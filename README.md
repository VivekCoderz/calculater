# Calculator

A calculator built with HTML, CSS and JavaScript.

## Features
- Digits, `00` and decimal point
- `+`, `-`, `*`, `/` and `%` (remainder)
- `AC` clears and `X` deletes the last character
- `=` evaluates the expression. Division by zero or an invalid expression shows `Error`
- A toggle switch at the top changes between the image background and a purple theme

## Run
Open `index.html` in a browser. There is no build step.

## Files
- `index.html`, `style.css`, `logic.js`: the calculator
- `cal_1.jpg`: background image used by the theme toggle
- `gh.c`: a separate C practice file, not part of the calculator
